Zeno vs Insomnia

Zeno started as a replacement for Insomnia: the same template syntax, the same shortcuts and a direct import of your Insomnia data, on a single screen without tabs and without an account.

Where Zeno is different

  • One screen. Sidebar, request, response. Insomnia 12 opens requests in tabs and has no setting to turn that off; Zeno never opens a tab.
  • Everything works without an account. Including the mock server, which in Insomnia needs a login.
  • Secrets can be committed without leaking. Zeno encrypts passwords and tokens inside the YAML files, so the whole folder can go to git. The encrypted values only open with the vault key in your OS keychain: on a teammate's machine they're entered again (or the key is shared). Insomnia keeps secret variables in a private environment that isn't synced, and exports confidential values in plain text.
  • Your Insomnia work comes over as it is. Zeno reads the installed Insomnia data folder (or a v4/v5 export), including environments, {% response %} chaining, scripts (insomnia.* is an alias), Insomnia-format plugins and the shortcuts you customized. See the migration guide.
  • Free, with no tiers. Zeno is MIT licensed and has no paid plan; Git storage isn't limited by user count.

Where Insomnia is the better choice

  • You need team features: cloud sync, organizations, SSO, enterprise vault integrations.
  • You use SOAP or Socket.IO, which Zeno doesn't support.
  • You design APIs with Insomnia's OpenAPI editor; Zeno imports OpenAPI but doesn't edit specs.
  • You prefer a tool backed by a company (Kong) with a larger community and signed builds. Zeno's builds are unsigned for now.

FAQ

Can I move my Insomnia collections to Zeno?

Yes. Zeno reads the installed Insomnia data folder or a v4/v5 export file, and keeps environments, folders, auth, scripts, template tags like {% response %} and your custom shortcuts.

Does Zeno need an account?

No. Zeno has no accounts and no telemetry; everything is stored in local files.

Is Zeno free?

Yes. Zeno is open source under the MIT license and has no paid tier.
